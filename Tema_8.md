### Создайте новый класс “ElectricCar” с методом “charge” и атрибутом емкость батареи. Реализуйте его наследование от класса, созданного в первом задании. Заставьте машину поехать, а потом заряжаться. Напишите комментарии для кода, объясняющие его работу. Результатом выполнения задания будет листинг кода с комментариями и получившийся вывод в консоль.
```python
class Car:
    def __init__(self, make, model):
        # Инициализируем атрибуты make и model
        self.make = make
        self.model = model

    def drive(self):
        # Выводим сообщение о вождении автомобиля
        print(f"Driving the {self.make} {self.model}")

# Создаем экземпляр Car и вызываем метод drive
my_car = Car("Toyota", "Corolla")
my_car.drive()

# Класс ElectricCar является подклассом Car и добавляет новый атрибут - battery_capacity
class ElectricCar(Car):
    def __init__(self, make, model, battery_capacity):
        # Вызываем инициализацию родительского класса
        super().__init__(make, model)
        # Добавляем атрибут battery_capacity (емкость батареи)
        self.battery_capacity = battery_capacity

    def charge(self):
        # Метод выводит сообщение о зарядке электромобиля
        print(f"Charging the {self.make} {self.model} with {self.battery_capacity} kWh")

# Создаем экземпляр ElectricCar и вызываем методы drive и charge
my_electric_car = ElectricCar("Tesla", "Model S", 75)
my_electric_car.drive()
my_electric_car.charge()

После этого создайте массив с фигурами, поместите туда круг и прямоугольник, затем при помощи цикла выведите их площади. Напишите комментарии для кода, объясняющие его работу. Результатом выполнения задания будет листинг кода с комментариями и получившийся вывод в консоль.
```python
class Shape:
    # Метод area является абстрактным методом и будет переопределен в дочерних классах
    def area(self):
        pass

class Rectangle(Shape):
    def __init__(self, width, height):
        # Инициализируем атрибуты ширины и высоты прямоугольника
        self.width = width
        self.height = height

    def area(self):
        # Метод вычисляет и возвращает площадь прямоугольника
        return self.width * self.height

class Circle(Shape):
    def __init__(self, radius):
        # Инициализируем атрибут радиуса круга
        self.radius = radius

    def area(self):
        # Метод вычисляет и возвращает площадь круга
        return 3.14 * self.radius * self.radius

# Создаем список фигур с объектами Rectangle и Circle
shapes = [Rectangle(5, 4), Circle(3)]

# Вызываем метод area для каждой фигуры в списке и выводим результат
for shape in shapes:
    print(shape.area())
```
